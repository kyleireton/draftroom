How rankings work
QB chip — weekly tier (T1 = elite, T6 = streaming). Color: purple.
RB/WR/TE chip — positional tier (T1 = best at position). Hover shows flex rank. Color by position: ■ RB ■ WR ■ TE.
DEF chip — weekly tier (T1 = best matchup). K chip — rank (#1 = best).
Slot logic: positional slots (RB, WR, TE) are filled first by the best available at that position, then FLEX slots by overall flex rank among the remainder.
⬆ START badge = bench/waiver player ranked better than a replaceable starter in a matching slot.
